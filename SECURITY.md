# Reporting a vulnerability

Ornyx Linux is in foundation development and has no supported release series yet. Include the affected source revision when reporting a concern.

Use the repository's GitHub Security tab and choose **Report a vulnerability** if available. If private reporting is unavailable, open a public issue asking a maintainer to arrange a private channel. Keep vulnerability details, credentials and personal data out of that issue.

In private, describe the affected component, edition, impact and observations needed to investigate. Maintainers will coordinate triage, remediation and disclosure with the reporter.
